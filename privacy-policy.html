Luvid プライバシーポリシー

最終更新日: 2026年11月17日 / 対象アプリ: Luvid（パッケージID: com.luvid.app）

Luvid（以下「本アプリ」）は、スマートフォン上でカメラ・外部USB映像音声入力・テロップ・BGM等を合成し、ライブ配信およびローカル録画を行うモバイルアプリケーションです。本プライバシーポリシーでは、本アプリにおけるユーザー情報および端末権限の取り扱いについて説明します。

1. 取得・利用する情報と端末権限

  • カメラ（CAMERA）および USB UVC デバイス
    ライブ映像のプレビュー表示、配信映像のエンコード、および端末内録画ファイルの生成のために使用します。開発者の外部サーバーへ映像データを収集・蓄積することはありません。
  • マイク（RECORD_AUDIO）および USB UAC / Bluetooth 音声機器（BLUETOOTH_CONNECT）
    配信および録画における音声の収音・ミキシングのために使用します。
  • ネットワーク通信（INTERNET）
    ユーザーが設定したライブ配信先（YouTube、RTMP、SRT、WHIP 等）への映像・音声データの送信、および YouTube Live 連携機能の通信のために使用します。
  • Google アカウント・YouTube Data API 連携情報
    ユーザーが任意で Google アカウント連携を行った場合のみ、YouTube ライブ配信枠の取得・作成・更新、ストリームキー取得、ライブチャットの取得のために、アカウント表示名・メールアドレス・チャンネル名および OAuth 認証トークンを使用します。取得した認証情報は端末内の暗号化領域（Android Keystore を用いたローカル保存）にのみ保存され、開発者サーバーへ送信・保存されることはありません。
  • ストレージ・メディアファイルへのアクセス
    録画動画（Movies/Luvid）やスナップショット画像（Pictures/Luvid）の保存、ならびにユーザーが選択したオーバーレイ画像（PNG/JPEG）および BGM 音声ファイルの読み込みに使用します。
  • 通知およびフォアグラウンドサービス権限（POST_NOTIFICATIONS / FOREGROUND_SERVICE）
    ライブ配信や録画がバックグラウンドに移行した場合でも安定して処理を継続し、配信・録画中であることを通知領域に明示するために使用します。

2. 第三者提供・広告・トラッキングについて

本アプリは、サードパーティの広告 SDK や行動分析・トラッキング SDK を組み込んでいません。ユーザーの個人情報を第三者へ販売、貸与、または不正に共有することはありません。なお、ライブ配信データおよび YouTube 連携通信は、ユーザー自身の操作により各配信プラットフォーム（Google LLC / YouTube 等）へ直接送信されます。

3. データの保持と削除

アプリ設定・シーン構成・ローカル BGM プレイリスト・認証トークンはユーザー端末内にのみ保存されます。アプリ内の「連携解除（サインアウト）」操作により Google / YouTube 連携トークンを削除できるほか、アプリをアンインストールすることで端末内のアプリデータはすべて削除されます。

4. セキュリティ対策

端末内に保存する認証セッション情報は Android Keystore（AES-GCM 暗号化）を用いて保護されており、クラウド自動バックアップ（allowBackup）を無効化しています。外部 API 通信には HTTPS を使用します。

5. プライバシーポリシーの変更

機能追加や法令・プラットフォーム要件の変更に伴い、本プライバシーポリシーの内容を改定することがあります。重要な変更がある場合は本ページにて告知します。
