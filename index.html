Luvid — モバイル ライブ配信スイッチャー

Luvid は、Android スマートフォン 1 台で外部 HDMI / USB UVC カメラと内蔵カメラを切り替え、テロップ・透過 PNG ロゴ・スライド・BGM をリアルタイム合成して YouTube Live 等へ配信およびローカル録画できるモバイルスイッチャーアプリです。
(Mobile live streaming switcher & local recorder supporting USB UVC/HDMI capture, scene overlays, audio mixing, and YouTube Live integration.)

主な機能 / Key Features

マルチカメラ＆UVC入力

USB UVC キャプチャ機器（外部 HDMI カメラ等）と端末の内蔵アウト／インカメラをシームレスに切り替え、露出・フォーカス・ズーム等を制御できます。

シーン＆オーバーレイ合成

テロップ2系統、透過PNGロゴ、全画面JPEGスライドショー、トランジション（カット／ディゾルブ等）をリアルタイムで映像に合成します。

マルチオーディオミキサー

内蔵マイク、USB オーディオ（UAC）、Bluetooth マイク、端末内 BGM 音声をチャンネル別ゲイン・コンプレッサー・ダッキングで調整可能です。

ライブ配信＆ローカル録画

RTMP / RTMPS / SRT による配信、マルチ配信、フォアグラウンド継続処理、ならびに端末ストレージ（Movies/Luvid）への MP4 同時録画に対応します。

Google アカウント / YouTube Live 連携について (Google API Disclosure)

Luvid は、ユーザーが希望した場合のみ Google OAuth 2.0 認証を通じて YouTube Data API v3 と連携し、配信準備や配信中コメントの表示を支援します。

  • 要求する権限と用途（Why we request YouTube scopes）： https://www.googleapis.com/auth/youtube.force-ssl、userinfo.profile、userinfo.email を使用し、ユーザー自身の操作により YouTube Live 配信枠（Broadcast）の取得・作成・タイトル/概要欄更新、RTMP/SRT ストリームキーの反映、ライブチャットコメントの取得・画面表示を行います。
  • データの保存と安全性（Local-only Storage & Limited Use）： 取得した認証トークン・チャンネル情報は、ユーザー端末内の Android Keystore（AES-GCM暗号化領域）にのみ保存され、開発者の外部サーバーへの送信・販売・広告利用は一切行いません。アプリ内の「連携解除」からいつでも削除できます。
  • 準拠ポリシー（Policy Compliance）： Luvid の Google API から受け取った情報の利用および他アプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。YouTube 連携のご利用にあたっては YouTube 利用規約 および Google プライバシーポリシー が適用されます。
